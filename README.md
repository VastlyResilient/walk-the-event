# Walk the Event
A cinematic, footage-first walk through the Nous Research event in NYC. Six grounded station exhibits, illustrated guide, floor map and station gallery.

## Run
`npm install && npm run dev`
`npm run build` creates `dist/` for static hosting.

Routes `/`, `/map`, `/stations`; deep links `#station-led-camera`, `#station-tvs`, `#station-projector`, `#station-space-screen`, `#station-merch`, `#station-cpu-terminals`, `#floor-up`, `#floor-down`.

See docs/HANDOFF.md for scope, verification and limitations.
